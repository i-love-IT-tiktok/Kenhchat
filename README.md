## ✨ **Giới thiệu**

</div>

> **Bio Page** là một ứng dụng web hiện đại cho phép người dùng **đăng bài viết, cảm nghĩ** kèm **file đính kèm** (ảnh, video, audio, tài liệu...). 
> 
> Mỗi bài viết đều có **bình luận không giới hạn** và **thả tim vô hạn** — mang đến trải nghiệm tương tác xã hội đầy đủ mà không cần đến backend phức tạp.
> 
> 💡 **Sử dụng GitHub làm database** — miễn phí 100%, không cần server, deploy 1-click lên Netlify!

<div align="center">

## 💡 **Ý tưởng**

</div>

> 📖 **Câu chuyện:** 
> 
> Mình muốn có một nơi đơn giản để chia sẻ cảm nghĩ hàng ngày — kiểu như một "bio page" cá nhân, nơi bạn bè có thể vào đọc, bình luận, và thả tim cho những gì mình viết.
> 
> Nhưng mà... dựng server thì tốn tiền. Firebase thì phức tạp. WordPress thì nặng.
> 
> Vậy nên mình nghĩ ra cách này: **dùng GitHub làm database**. Mỗi lần đăng bài = 1 commit. Mỗi file upload = 1 file trong repo. Miễn phí, minh bạch, và có version control luôn!
> 
> Sau đó deploy frontend lên Netlify — thế là có ngay một app xịn sò, chạy global, không tốn đồng nào. 🎉

<br/>

| 👥 | Nhóm bạn muốn có "group feed" riêng tư |

## 📂 **Cấu trúc dự án**

</div>

```bash
bio-app/
│
├── 📄 index.html              # 🎨 Trang chính + form đăng nhập/đăng ký
├── 🎨 style.css               # 💅 Style toàn bộ giao diện
├── ⚙️  config.js               # 🔧 Cấu hình (GitHub, users mặc định)
├── 🧠 app.js                  # 🚀 Logic chính của app
├── 🌐 netlify.toml            # ☁️  Config deploy Netlify
├── 📖 README.md               # 📚 File này
├── 🚫 .gitignore              # 🗑️  Bỏ qua file không cần thiết
├── 📜 LICENSE                 # ⚖️  MIT License
│
└── 📁 data/
    ├── 📋 data.json           # 💾 Database dạng JSON (posts, users)
    └── 📁 uploads/            # 📎 File đính kèm của bài viết
        └── 📄 .gitkeep        # Giữ folder khi trống
```


📝 Chi tiết từng file

<details>
<summary><b>📄 index.html</b> — Trang chính</summary>
Chứa toàn bộ markup:

· Màn hình đăng nhập / đăng ký (auth screen)
· Màn hình chính (app screen)
· Form đăng bài
· Container render danh sách bài viết

</details><details>
<summary><b>🎨 style.css</b> — Style toàn bộ</summary>
Bao gồm:

· Reset CSS
· Gradient background
· Card component
· Button style (gradient, hover animation)
· Form input style
· Post / Comment / Attachment style
· Animation (pop, fadeIn)
· Responsive media queries

</details><details>
<summary><b>⚙️ config.js</b> — Cấu hình</summary>
Chứa các hằng số:

· GITHUB_USER — username GitHub
· GITHUB_REPO — tên repo
· GITHUB_BRANCH — branch (main/master)
· GITHUB_TOKEN — Personal Access Token
· DATA_PATH — đường dẫn file JSON
· UPLOAD_PATH — đường dẫn folder upload
· USERS — danh sách user mặc định

</details><details>
<summary><b>🧠 app.js</b> — Logic chính</summary>
Các module chính:

· GitHub helpers — ghGetFile, ghPutFile, ghDeleteFile
· Base64 utils — utf8ToBase64, base64ToUtf8, fileToBase64
· Data layer — loadData, saveData
· Auth — doLogin, doRegister, doLogout
· Render — renderPost, renderFile
· Actions — submitPost, likePost, submitComment, deletePost, deleteComment

</div><details>
<summary><b>❌ Lỗi "Cần token GitHub trong config.js"</b></summary>
Nguyên nhân: Chưa điền GITHUB_TOKEN trong config.js.

Cách fix:

1. Mở config.js
2. Điền token vào GITHUB_TOKEN: 'github_pat_xxx...'
3. Lưu lại và deploy lại Netlify

</details><details>
<summary><b>❌ Lỗi "GitHub write error: 401"</b></summary>
Nguyên nhân: Token không hợp lệ hoặc hết hạn.

Cách fix:

1. Vào https://github.com/settings/tokens
2. Kiểm tra token còn hoạt động không
3. Nếu hết hạn → tạo token mới
4. Cập nhật config.js

</details><details>
<summary><b>❌ Lỗi "GitHub write error: 403"</b></summary>
Nguyên nhân:

· Token thiếu quyền Contents: Read and write
· Hoặc vượt rate limit

Cách fix:

1. Kiểm tra permissions của token
2. Đảm bảo có Contents: Read and write
3. Chờ 1 giờ nếu vượt rate limit

</details><details>
<summary><b>❌ File upload không hiển thị</b></summary>
Nguyên nhân:

· File chưa push lên GitHub thành công
· Hoặc đang cache

Cách fix:

1. Kiểm tra folder data/uploads/ trong repo
2. Nếu file có trong repo → refresh trình duyệt (Ctrl+Shift+R)
3. Nếu không có → có thể do file quá 24MB

</details><details>
<summary><b>❌ Đăng nhập không được</b></summary>
Nguyên nhân: User không có trong data.json.

Cách fix:

1. Mở data/data.json trong repo
2. Kiểm tra mảng users
3. Thêm user mới nếu cần
4. Commit → thử lại

</details><details>
<summary><b>❌ Trang bị trắng (blank page)</b></summary>
Nguyên nhân: Lỗi JavaScript.

Cách fix:

1. Mở DevTools (F12) → Console
2. Xem lỗi cụ thể
3. Kiểm tra config.js có syntax đúng không
4. Đảm bảo các file load đúng thứ tự

</details><details>
<summary><b>❌ Rate limit GitHub API</b></summary>
Nguyên nhân: Vượt 5000 requests/giờ (không có token) hoặc 5000/giờ (có token).

Cách fix:

· Chờ 1 giờ
· Hoặc giảm setInterval refresh từ 15s → 60s
· Hoặc dùng Personal Access Token để tăng limit

</details>---

<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;600;700&display=swap" rel="stylesheet">

body { font-family: 'Poppins', sans-serif; }

<summary><b>🌙 Thêm Dark Mode</b></summary>
Thêm nút toggle và CSS:

```css
body.dark {
  background: linear-gradient(135deg, #232526, #414345);
  color: #e0e0e0;
}
body.dark .card { background: #2a2a2a; color: #e0e0e0; }
```

JS:

```javascript
function toggleDark() {
  document.body.classList.toggle('dark');
  localStorage.setItem('dark', document.body.classList.contains('dark'));
}
```
